## ۲) آزمون شرطی روی دادهٔ قیمت (واقعی)

```
رویدادهای منطبق با دادهٔ قیمت محلی: ۲۴۶
برچسب پس از افشا (۳ جلسه):
  مثبت (≥ +۳٪): ۱۵۰  (۶۱٪)
  منفی (≤ −۳٪):  ۲۵  (۱۰٪)
  خنثی:         ۷۱  (۲۹٪)

ویژگی‌های T-1 (شب قبل از افشا):
  volume_ratio: میانگین ۱.۵۶ · میانه ۱.۲۷ · صدک۹۰ ۵.۰۲
  proximity به سقف ۶۰ روزه: میانگین ۰.۷۷۸ · میانه ۰.۷۳۹
  بازده ۲۰ روزه: میانگین −۲.۳٪ (درینت منفی!)

قاعدهٔ ورود (vol>1.8 و prox≥0.9) روی T-1 قبل از رویداد: فقط ۱۰.۹۸٪ مواقع فعال شده
```

### آزمون اصلی (همهٔ روز-نمادها)

| معیار | مقدار |
|---|---|
| روز-نماد بررسی‌شده | ۱۸,۶۰۰ |
| نرخ پایه (رویداد در ۱۰ جلسهٔ آینده) | ۰.۳۰٪ |
| روزهای سیگنال | ۱,۵۷۰ |
| نرخ برخورد سیگنال | ۰.۱۳٪ |
| **lift** | **۰.۴۳** (بدتر از تصادف) |
| بازده ۳ روزه بعد از سیگنالِ دارای رویداد | +۸.۹۴٪ |
| بازده ۳ روزه بعد از سیگنالِ بدون رویداد | +۱.۴۶٪ |

**نتیجه:** سیگنال حجم/قیمت، افشای الف را پیش‌بینی نمی‌کند (lift < ۱).
ولی اگر رویدادی رخ دهد، بازده ۳ روزهٔ بعدش تقریباً ۶ برابر است (+۸.۹٪ در برابر +۱.۵٪).

## ۳) کشف مهم: سوگیری داده در فیلتر تاریخ کدال

```
توزیع روزهای انتشار در دیتاست: ۹۴.۶٪ در روزهای ۲۸–۳۱ ماه‌های ۳/۶/۹/۱۲
اگر تصادفی بود: ۷.۷٪  →  lift ظاهری ۱۲.۳×

اما این یک «اثر ابزار جمع‌آوری» است، نه یافتهٔ بازار:
  پارامتر FromDate/ToDate در API کدال روی «پایان دورهٔ مالی» فیلتر می‌کند،
  نه تاریخ انتشار. (آزمون: پنجرهٔ ۱۴۰۴/۰۴/۰۱..۱۴۰۴/۰۴/۳۱
   همهٔ نتایج را با PublishDateTime = ۱۴۰۴/۰۴/۳۱ برگرداند)
```

**پس ادعای «۹۴.۶٪ افشاها پایان فصل است» معتبر نیست — آرتیفکت است.**
و آزمون شرطی بخش ۲ هم با همین نمونهٔ سوگیری‌شده انجام شده؛
جهت نتیجه (lift<۱) محتملاً درست است، ولی عدد نهایی نیاز به نمونهٔ بی‌سوگیری دارد.

### نتیجهٔ نهایی (اصلاح‌شده)

```
۱) سیگنال حجم/قیمت افشای الف را پیش‌بینی نمی‌کند (lift ۰.۹۵ ≈ ۱)
۲) برخلاف فرض اولیه، حجم قبل از افشا کمتر از میانگین است (میانه ۰.۶۴۵)
   → «دریفت قبل از افشا» در این دیتاست دیده نمی‌شود
۳) اگر افشا رخ دهد، بازده ۳ روزه +۳.۳۲٪ در برابر +۱.۳۴٪ بدون افشا
   → پاداش رویداد واقعی است، ولی سیگنال آن را پیدا نمی‌کند
۴) ادعای «۹۴.۶٪ پایان فصل» رد شد (آرتیفکت فچ)
```
