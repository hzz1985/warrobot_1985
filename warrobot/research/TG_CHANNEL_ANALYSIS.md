## ۵) ارزیابی صادقانه: آیا اطلاعات کانال به استراتژی سودده تبدیل می‌شود؟

### آنچه هنوز ممکن نیست
```
۲۰ پیام در ۳ روز = برای آمار کافی نیست
برای آزمون «حباب بالا → فروش / حباب پایین → خرید» نیاز به:
  - سری زمانی چند هفته‌ای حباب (intraday)
  - یا بازسازی حباب از دادهٔ رسمی (قیمت صندوق + انس جهانی + نرخ ارز)
```

### مسیر پیشنهادی (اجرایی)
```
۱) جمع‌آوری خودکار هر ۱۵ دقیقه از ۰۹:۰۰ تا ۱۷:۰۰ ✔ (همین حالا فعال شد)
   → در ۳–۴ هفته: ~۲۰۰۰ نمونهٔ intraday

۲) بازسازی مستقل حباب (برای بی‌نیازی از کانال):
   حباب ≈ قیمت داخلی گواهی / (انس جهانی × نرخ ارز) − ۱
   نرخ ارز: باید از منبع در دسترس تهیه شود (bonbast مسدود)

۳) بک‌تست پس از جمع‌آوری:
   سیگنال: حباب < آستانهٔ پایین (تخفیف) → خرید صندوق
           حباب > آستانهٔ بالا (حباب) → فروش
   خروج: بازگشت حباب به میانه یا حد ضرر ۴٪

۴) اگر بک‌تست مثبت و پایدار بود:
   منطق با دادهٔ خودمان (TSETMC + انس جهانی + نرخ ارز) پیاده می‌شود
   و کانال فقط «اعتبارسنجی» است، نه منبع عملیاتی
```
