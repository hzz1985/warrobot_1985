**تاریخ اجرا:** ۱۴۰۵/۰۸/۲۳ · **وضعیت:** فاز ۱ و ۳ اجرا شد · فاز ۲ نیمه‌کاره (محدودیت نرخ کدال)

> این گزارش فقط شامل اعدادی است که **واقعاً اندازه‌گیری شده‌اند**. هر جا داده در دسترس نبوده، صریح نوشته شده و هیچ عددی جعل نشده است.

## ۰) خلاصهٔ مدیریتی (صادقانه)

```
آنچه واقعاً سنجیده شد:
  ✔数据集 قیمت/حجم: ۷۹۰ نماد · ۱۴۰۴/۰۱/۰۵ تا ۱۴۰۵/۰۸/۲۰ (TSETMC محلی)
  ✔ بک‌تست کامل قاعدهٔ حجم+نزدیکی به سقف روی همین داده: ۵,۸۲۴ معامله
  ✔ احتمال پیشروی: P(+۳٪ در ۳ روز بعد از سیگنال) = ۵۵.۶۱٪

آنچه سنجیده نشد و باید صادقانه گفت:
  ✘ لیست کامل «اطلاعیه الف» از کدال: فقط ۱۲ رویداد جمع شد (HTTP 429)
     → آزمون «شرطی» (P(اطلاعیه الف | سیگنال)) هنوز ممکن نیست
  ✘ دادهٔ کالایی/ارزی/خبری در بک‌تست وارد نشد (منابع: ime, shana, irna در دسترس؛
     bonbast و nrb مسدود؛ LME خطای 403)

نتیجهٔ کلیدی و منفی:
  قاعدهٔ قیمت/حجم تنها، با نرخ بدون ریسک ۲۳٪، شارپ منفی دارد (−۹.۰)
  → این قاعده به‌تنهایی «سودآور» نیست؛ ارزش آن فقط به‌عنوان پیش‌فیلتر است
```

## ۱) فاز ۱ — پژوهش سیگنال‌ها

### ۱.۱ ناهنجاری حجم و قیمت (Pre-disclosure drift)

| مورد | توضیح |
|---|---|
| مبنای نظری | معامله‌گران مطلع قبل از افشا وارد می‌شوند → حجم غیرعادی و دریفت قیمت |
| اندازه‌گیری | `vol_ratio = Volume_t / MA20(Volume)` و `proximity = Close / max(High, 60)` |
| منبع | TSETMC (فایل‌های روزانهٔ محلی + API) |
| سرعت ظهور | ۱ تا ۱۰ روز قبل از افشا (طبق ادبیات، این‌جا قابل‌آزمون نیست بدون رویدادها) |
| دقت واقعی اندازه‌گیری‌شده | P(+۳٪ در ۳ روز پس از سیگنال) = **۵۵.۶۱٪** (غیرشرطی) |

### ۱.۲ شاخص‌های بنیادی پیشرو

```
منابع در دسترس: ime.co.ir (۲۰۰) · shana.ir (۲۰۰) · fipiran.com (۲۰۰)
منابع مسدود : bonbast.com (قطع اتصال) · nrb.ir (DNS) · lme.com (403)
وضعیت: در بک‌تست وارد نشد → «سیگنال کیفی»
```

### ۱.۳ الگوهای زمانی (تقویمی)

```
منبع: codal.ir (search API با Category=2 و فیلتر عنوان «گروه الف»)
وضعیت: ۱۲ رویداد واقعی جمع‌آوری شد، سپس سرور کدال HTTP 429 داد
نمونهٔ واقعی: خاور ۱۴۰۰/۰۳/۳۰ ۱۵:۵۸ — «انعقاد قرارداد مهم - گروه الف»
           شپارس ۱۴۰۰/۰۳/۳۱ ۰۸:۴۴ — «دریافت مجوز تغییر بیش از ۱۰٪ نرخ فروش - گروه الف»
→ توزیع فاصلهٔ افشا از پایان فصل: نیاز به دیتاست کامل (در انتظار)
```

```

```

### قواعد اجراشده
```
ورود: vol_ratio > 1.8  و  Close ≥ 0.90 × سقف ۶۰ روزه
ورود در Open روز بعد (بدون Look-ahead)
خروج: +۸٪ هدف · −۴٪ حد ضرر · ۱۰ روز معاملاتی
کارمزد: ۱٪ رفت‌وبرگشت · حداکثر ۳ پوزیشن هم‌زمان
```

## ۴) فاز ۴ — نتایج

### ۴.۱ جدول قدرت سیگنال

| سیگنال | سرعت ظهور (روز) | دقت | در دسترس بودن داده |
|---|---|---|---|
| حجم نسبی >۱.۸ + نزدیکی به سقف ۳ماهه | ۱–۱۰ | P(+۳٪ در ۳ روز)=۵۵.۶۱٪ (غیرشرطی) | ✔ کامل (TSETMC) |
| الگوی زمانی فصلی افشا | ۰–۳۰ | نامعلوم | ✘ کدال محدود |
| تغییر قیمت کالای پایه | ۵–۳۰ | نامعلوم | △ IME در دسترس |
| تغییر نرخ ارز | ۵–۳۰ | نامعلوم | ✘ مسدود |
| خبر مثبت بخشی | ۱–۷ | کیفی | △ irna/shana |
| افزایش مالکیت سهامداران عمده | ۵–۳۰ | کیفی | △ TSETMC API |

### ۴.۲ رده‌بندی صنایع
> **قابل محاسبه نیست** — نیازمند دیتاست کامل رویدادهای گروه الف. روش پیشنهادی: نرخ رویداد به‌ازای هر نماد-سال به تفکیک صنعت (codal Category=2 + فیلتر گروه الف + گروه صنعت فپیپیران).

### ۴.۳ جدول بک‌تست
(همان جدول بخش ۳)

### ۴.۴ پنج معیار برتر برای اسکرینینگ

| رتبه | معیار | آستانه | پشتوانهٔ واقعی |
|---|---|---|---|
| ۱ | حجم نسبی | > ۱.۸× میانگین ۲۰ روزه | منجر به P(+۳٪)=۵۵.۶٪ |
| ۲ | نزدیکی به سقف ۶۰ روزه | ≥ ۹۰٪ | شرط هم‌زمان با ۱ |
| ۳ | حجم ارزش معاملات | ≥ ۱۰ میلیارد ریال | جلوگیری از نمادهای بی‌نقد |
| ۴ | ثبات زمانی افشاهای قبلی | انحراف معیار < ۷ روز | نیازمند دیتاست کدال |
| ۵ | فاصله از پایان فصل | ۰–۳۰ روز | نیازمند دیتاست کدال |

### ۴.۵ محدودیت‌ها و ریسک‌ها

```
۱) کدال با HTTP 429 محدود شد → دیتاست رویداد ناقص (۱۲ از هزاران)
۲) دادهٔ قیمت فقط ۱۴۰۴-۱۴۰۵ (۱.۵ سال) — «چندساله» نیست
۳) کالا/ارز/خبر در بک‌تست وارد نشد
۴) شارپ منفی: قاعدهٔ قیمت/حجم از نرخ بدون ریسک ۲۳٪ عقب است
   → ارزش آن «فیلتر اولیه» است، نه استراتژی کامل
۵) کارمزد ۱٪ رفت‌وبرگشت فرض شد؛ در نمادهای کم‌عمق بیشتر است
۶) ریسک نقدشوندگی، توقف نماد، و تغییر قوانین لحاظ نشده
۷) Look-ahead کنترل شد (ورود در Open روز بعد) ولی survivor bias کنترل نشده
```

### ۴.۶ ساخت واچ‌لیست زنده

```
هر شب (۲۱:۱۵ به بعد):
  ۱) به‌روزرسانی دادهٔ روزانهٔ TSETMC (nightly_download.py)
  ۲) محاسبه برای همهٔ نمادها: vol_ratio، proximity، ارزش معاملات
  ۳) فیلتر: vol_ratio>1.8 و proximity≥0.9 و ارزش≥۱۰ میلیارد
  ۴) افزودن لایهٔ کدال: نمادهایی که در ۳۰ روز آینده احتمال افشای فصلی دارند
     (نیازمند دیتاست کامل رویداد)
  ۵) خروجی: state/typeA_watchlist.csv با ستون‌های امتیاز و دلیل
  ۶) ارسال به وب‌اپ/ایمیل صبح
```
