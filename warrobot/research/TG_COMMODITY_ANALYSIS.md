## ۳) چرا این داده ارزشمند است

```
این پست دقیقاً «حباب» هر گواهی نسبت به قیمت جهانی/فیزیکی را می‌دهد
حباب = فاصلهٔ قیمت داخلی از ارزش منصفانه
  حباب منفی  = تخفیف  → فرصت خرید (در صورت بازگشت به میانه)
  حباب مثبت  = گران‌فروشی → فرصت فروش / پرهیز از خرید

این همان اطلاعاتی است که برای «بورس کالا» لازم است
و سرمایه‌گذاری تو فقط طلا/نقره نیست — همهٔ این ۱۲ مورد را پوشش می‌دهد
```

## ۴) استراتژی قابل آزمون (فرضیه)

```
فرضیه: حباب، میانگین‌گرا (mean-reverting) است
  - خرید گواهی‌هایی که حباب منفی عمیق دارند (روی −۲۰٪، میلگرد −۳.۳٪، مس −۲.۹٪، طلا −۲.۸٪)
  - فروش/پرهیز از حباب‌های بالا (T9 +۴۷.۶٪، گندله +۲۶.۳٪، پسته +۶.۷٪)
  - خروج: بازگشت حباب به صفر یا میانهٔ ۳۰ روزه

نکتهٔ مهم: در این لحظهٔ خاص، پراکندگی حباب بسیار زیاد است (−۲۰.۲٪ تا +۴۷.۶٪)
که نشان می‌دهد فرصت‌های cross-sectional وجود دارد — ولی یک عکس لحظه‌ای «سند» نیست
```

```
               خودکار در tg_commodity_daily.jsonl ذخیره می‌شود
پس دادهٔ لازم خودش جمع می‌شود — بدون کار دستی
```

## ۶) در صورت تأیید استراتژی (قدم بعد)

```
۱) بک‌تست میانگین‌گرایی: بعد از ۴–۸ هفته داده
   - همبستگی حباب امروز با بازده ۵/۱۰/۲۰ روز آیندهٔ همان گواهی
   - نرخ بازگشت حباب به میانه
۲) بک‌تست cross-sectional:
   - ۳ کالای با کمترین حباب را بخر، ۳ کالای با بیشترین حباب را نفروش/کنار بگذار
۳) شبیه‌سازی با کارمزد واقعی IME و مالیات بر ارزش افزوده
۴) اگر سودده بود: ماژول جداگانه در ربات (بازار کالا، نه سهام)
```

## ۷) هشدارهای واقعی

```
۱) حباب منفی می‌تواند ماه‌ها باقی بماند (ریسک بازگشت نکردن)
۲) نقدشوندگی گواهی‌ها متفاوت است؛ حباب −۲۰٪ روی کاغذ خوب است ولی ممکن است فروشنده نداشته باشد
۳) مالیات بر ارزش افزوده هنگام تحویل فیزیکی، بازده را کم می‌کند
۴) داده‌های این پست خودکار است ولی باید با قیمت واقعی معاملات صحت‌سنجی شود
۵) یک عکس روزانه = نمونه نیست؛ استراتژی روی یک مشاهده ساخته نمی‌شود
```
