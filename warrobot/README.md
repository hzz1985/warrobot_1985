# TseRobotV3 — ربات فاصله تا سقف (باند ۰٫۲۵٪)

ربات جدید که فقط بر اساس ویژگی «فاصله تا سقف» و نتیجهٔ بک‌تست باند **۰–۰٫۲۵٪** کار می‌کند.

## منطق

```
سقف هر نماد = قیمت پایانی دیروز × (۱ + درصد نوسان)
فاصله       = (سقف − قیمت بسته) ÷ قیمت بسته × ۱۰۰

کاندید = فاصله ≤ ۰٫۲۵٪   (یعنی قفل روی سقف)
```

| مرحله | ساعت | کار |
|---|---|---|
| اسکن شبانه | ۲۱:۲۰ | ساخت `state/candidates.csv` از دادهٔ روزانه (مرتب بر اساس ارزش معاملات) |
| اسکن زنده | ۰۹:۰۰ | تأیید با دفتر ۵ سطح: نبود فروشنده روی سقف + صف ≥ ۳۰۰ میلیون ریال |
| خرید | ۰۹:۰۱–۰۹:۲۰ هر ۱۰ ثانیه | خرید روی سقف، حجم از قدرت خرید لحظه‌ای، چانک با آستانه حجم |
| فروش | هر ۶۰ ثانیه | حد سود ۱۲٪ · حد ضرر ۵٪ · حداکثر ۱۵ جلسه |

## چرا این اعداد

از بک‌تست شبکه‌ای ۱۴۰۵ (۵۶۰ ترکیب):

```
باند ۰–۰٫۲۵٪  →  میانگین +۱٫۶۹٪ با TP12/SL5  و  +۳٫۱۰٪ با TP25/SL3
باند ۰٫۲۵–۰٫۵٪ →  +۰٫۰۵٪  و  +۰٫۳۵٪
بقیهٔ باندها   →  صفر یا منفی
```

پس تنها فیلتر ورود، همین باند است و خروج با TP 12٪ / SL 5٪ (قابل تغییر در `config.json`).

## اجرا

```bash
python run.py scan          # اسکن شبانه
python run.py live          # ۰۹:۰۰ تأیید زنده + ایمیل
python run.py buy --dry     # تست خرید
python run.py buy           # خرید واقعی
python run.py sell          # حلقهٔ فروش
python run.py daemon        # همهٔ برنامه‌ها
```

## ساختار

```

```
