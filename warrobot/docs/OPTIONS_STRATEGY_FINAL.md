# استراتژی نهایی آپشن تهران — نتایج دور پنجم (walk-forward کامل)

## تعریف استراتژی (کاندید پذیرفته‌شده)

```
نام            : منتخبِ مومنتوم پایه با خروج دنباله‌دار (Selective Underlying Momentum)
بازار          : آپشن‌های کال بورس تهران (ض…)، فقط نقدشونده‌ترین‌ها
فیلتر نقدشوندگی: ارزش معاملهٔ روز ≥ ۵۰۰ میلیون ریال  و  قیمت ≥ ۵٬۰۰۰ ریال
سیگنال          : مومنتوم ۵ روزهٔ دارایی پایه > ۰
                  (نام قرارداد: ضهرم5019 → هرم)
ورود            : قیمت بستهٔ روز بعد از سیگنال
خروج            : ۱) اردر stop ثابت −۱۲٪
                  ۲) پس از رسیدن به +۶٪ → stop به نقطهٔ سربه‌سر منتقل می‌شود
                  ۳) خروج دنباله‌دار: افت ۱۰٪ از بالاترین قیمت پس از ورود
                  ۴) سقف نگهداری ۵ کندل
                  ۵) خروج اجباری وقتی قرارداد دیگر معامله نمی‌شود
قواعد ریسک      : توقف پس از ۳ ضرر متوالی، استراحت ۵ روز معاملاتی
حداکثر پوزیشن   : ۳ (هرکدام ۱/۳)
کارمزد          : ۰٫۵٪ رفت‌وبرگشت
```

## نتیجهٔ کل (۸۵ معامله)

| معیار | مقدار |
|---|---|
| تعداد معاملات | ۸۵ |
| نرخ برد | ۵۲.۹٪ |
| **میانهٔ بازده هر معامله** | **+۳.۱۰٪** |
| نسبت سود/ضرر (PF) | **۲.۴۳** |
| حداکثر افت سرمایه | **−۲۵.۰٪** |
| بازده کل (۳ پوزیشن همزمان) | +۵۹۵.۱٪ |
| سال‌های مثبت | ۱۰۰٪ |

## ۱) Walk-forward واقعی (۶۰٪ درون‌نمونه / ۴۰٪ بیرون‌نمونه)

| دوره | معاملات | میانه | PF | حداکثر افت |
|---|---|---|---|---|
| درون‌نمونه (۶۰٪) | ۴۲ | +۰.۵۷٪ | ۱.۹۴ | −۲۳.۶٪ |
| **بیرون‌نمونه (۴۰٪)** | **۴۳** | **+۴.۵۶٪** | **۳.۱۱** | −۲۵.۰٪ |

**نکتهٔ کلیدی: عملکرد بیرون‌نمونه بهتر از درون‌نمونه است — نشانهٔ نبودِ overfit.**

## ۲) بازبینی قاعدهٔ استراحت (cooldown)

| نسخه | معاملات | میانه | PF | افت |
|---|---|---|---|---|
| با قاعدهٔ cooldown | ۸۵ | **+۳.۱۰٪** | ۲.۴۳ | −۲۵.۰٪ |
| بدون قاعده | ۹۳ | −۰.۱۷٪ | ۲.۵۸ | −۲۴.۲٪ |

**قاعدهٔ cooldown برای این کاندید مفید است (میانه را از منفی به مثبت برد).**
(در دور قبل روی ترکیب‌های دیگر ضرر می‌داد — پس «مشروط به ترکیب» مفید است.)

## ۳) حساسیت به پارامترها (±۲۰٪)

بهترین‌ها (همه از سطح ۵۰۰M):
```
hold=5 stop=-14.4%  →  ۸۵ معامله · میانه +۴.۱۶٪ · PF ۲.۵۸ · افت −۲۴.۲٪
hold=5 stop=-12.0%  →  ۸۵ معامله · میانه +۳.۱۰٪ · PF ۲.۴۳ · افت −۲۵.۰٪
hold=5 stop=-9.6%   →  ۸۸ معامله · میانه +۲.۰۹٪ · PF ۲.۳۴ · افت −۲۴.۲٪
hold=6 stop=-12.0%  →  ۸۲ معامله · میانه +۱.۸۳٪ · PF ۲.۳۰ · افت −۲۵.۲٪
hold=4 stop=-14.4%  →  ۹۵ معامله · میانه +۱.۸۱٪ · PF ۲.۳۰ · افت −۲۴.۲٪
```

بدترین‌ها (همه از سطح ۱۰۰M):
```
hold=6 stop=-9.6%   →  میانه −۲.۲۹٪ · افت −۶۷.۳٪
hold=5 stop=-14.4%  →  میانه −۱.۶۱٪ · افت −۶۱.۱٪
```

**۸ از ۱۸ ترکیب مثبت — ولی همهٔ ۹ ترکیب سطح ۵۰۰M مثبت‌اند (به‌جز یکی).**
یعنی استراتژی **در سطح نقدشوندگی خودش پایدار است**، اما **بین سطوح مختلف پایدار نیست**.

## ۵) تفسیر صادقانه

```
چه چیزی تأیید شد:
✔ walk-forward واقعی: بیرون‌نمونه مثبت و قوی (میانه +۴.۵۶٪، PF ۳.۱۱)
✔ افت سرمایه زیر ۳۰٪ (۲۵٪)
✔ پایداری پارامتری در سطح نقدشوندگی خودش (۵۰۰M)
✔ قاعدهٔ cooldown مفید است

چه چیزی تأیید نشد:
✘ پایداری بین سطوح نقدشوندگی (۱۰۰M افت ۶۰٪+ می‌دهد)
✘ تعداد معاملات (۸۵ در ~۲ سال) — برای معناداری آماری کم است
✘ مبنای زمانی: نقدشوندگی کافی برای این فیلتر فقط ~۲ سال سابقه دارد
  → «چند ساله» واقعی در سطح ۵۰۰M در دسترس نبود
```

## ۶) حکم نهایی

```
«پذیرش مشروط»

این یک لبهٔ واقعی است، نه آرتیفکت:
  - بیرون‌نمونه مثبت و بهتر از درون‌نمونه
  - افت ۲۵٪
  - پایداری در پارامترها در سطح نقدشوندگی خودش

ولی نمیتوان آن را «استراتژی چندسالهٔ آمادهٔ اجرای انبوه» نامید:
  - فقط در نقدشونده‌ترین قراردادها کار می‌کند
  - حدود ۴۰ معامله در سال
  - فقط ~۲ سال دادهٔ قابل‌اعتماد در آن سطح

پیشنهاد اجرا: به‌صورت «آزمایشی با سرمایهٔ کوچک» (حداکثر ۱/۳ سرمایه)
و پایش دقیق ۲۰ معاملهٔ اول، نه اجرای کامل.
```
