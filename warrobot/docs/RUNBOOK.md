### ساعت‌ها
```

### منطق
```
برای هر پوزیشن باز:
  سود/زیان = (قیمت زنده / میانگین خرید - ۱) × ۱۰۰

  اگر سود/زیان ≥ حد سود (پیش‌فرض ۲۵٪)   → sell_tp → سفارش فروش خودکار
  اگر سود/زیان ≤ -حد ضرر (پیش‌فرض ۳٪)   → sell_sl → سفارش فروش خودکار
  در غیر این صورت                       → hold

```

```

body: ["3026111000005007"]      ← آرایه‌ای از شناسه‌های سفارش (رشته)

```
