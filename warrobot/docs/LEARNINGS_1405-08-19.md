# دانش امروز (۱۴۰۵-۰۸-۱۹) — آنچه ربات از فردا باید انجام دهد

این سند به‌صورت «قاعدهٔ اجرایی» نوشته شده و با `selfcheck_rules.py` روزانه راستی‌آزمایی می‌شود.

## قاعده ۱ — لغو سفارش فقط از یک مسیر
```
درست:
  POST https://api.meibours.ir/Web/V1/Order/Delete
  body: ["<orderid>", ...]         ← آرایهٔ رشته‌ای
  پاسخ: {"Data":[{"SuccessCancel":true}],"IsSuccessfull":true}

نادرست (همه شکست خورده‌اند):
  body {"orderId": ...} / {"OrderId": ...}  → 400 InputDataNotValid
  verb DELETE                                → 405
  /Order/Cancel | CancelOrder | DeleteOrder  → مسیر جعلی
  کلیک روی ردیف گرید سفارشات باز             → ردیف دکمهٔ حذف ندارد
```

## قاعده ۲ — چرخش ۱۰:۰۰
```
۱) سفارش‌های باز از API خوانده می‌شود (JSON تمیز، نه regex)
۲) هر سفارش با executed < qty  = پرنشده
۳) با /Order/Delete لغو می‌شود
۴) کاندیدای بعدی از candidates.csv یا reserve.csv سفارش می‌گیرد
۵) همهٔ مراحل در orders_log.jsonl و cancel_log.jsonl ثبت می‌شود
```

## قاعده ۳ — ساعت ۰۸:۴۵:۰۱
```
زمان‌بند قبل از اجرای job سفارش، تا ثانیهٔ ۰۱ صبر می‌کند (wait_for_084501)
ترتیب در ۰۸:۴۵: اول سفارش، بعد ایمیل آمادگی
```

## قاعده ۴ — پرتفوی و دفتر
```
منبع اصلی وب‌اپ: state/broker_portfolio.json (پرتفوی واقعی کارگزاری)
۲۱:۲۰ portfolio_sync → ۲۱:۲۱ ledger_sync (همسان‌سازی دفتر)
وب‌اپ هرگز از دفتر تنها نمایش نمی‌دهد
```

## قاعده ۵ — پول بلوکه
```
کل سفارش‌های باز = BlockedBalance
سفارش نوع «روز» پایان روز خودبه‌خود منقضی می‌شود و پول آزاد می‌گردد
قبل از هر سفارش جدید: موجودی آزاد (AccountBalance) بررسی شود
```

## قاعده ۶ — سود به افران (موقت)
```
هر فروش موفق → سود محقق‌شده → خرید خودکار افران
افران هرگز توسط ربات فروخته نمی‌شود (MANUAL_ONLY)
این قاعده موقتی است تا اعلام لغو
```

## قاعده ۷ — آمادگی سه‌مرحله‌ای
```
۰۸:۳۰ · ۰۸:۴۰ · ۰۸:۴۵  ایمیل آماده/ناآماده
اگر ناآماده: علت + اقدام دستی لازم
```

## قاعده ۸ — خروج‌ها
```
۰۹:۰۰–۱۲:۳۰ هر ۳ دقیقه: پایش TP/SL
خروج: stop ثابت · break-even · trail · سقف نگهداری
ایمیل هنگام هر فروش
```

## قاعده ۹ — محافظ‌های سفارش
```
بایند دقیق (نام bindشده = نام درخواستی) وگرنه abort
قیمت داخل دامنهٔ مجاز (از پنل/پایانی، نه سقف دیروز)
سایز = یک‌سوم کل دارایی، سقف = موجودی آزاد × ۰.۹۵
```

## قاعده ۱۰ — اعتبارسنجی روزانه
```
۰۸:۲۵ selfcheck_rules.py: همهٔ قواعد بالا را چک می‌کند
اگر چیزی خراب بود: ایمیل + ثبت در state/rules_status.json
```
