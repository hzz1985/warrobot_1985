# WarRobot — ربات معاملاتی بورس تهران

ربات خودکار معامله در بازار سهام ایران (مهر اقتصاد / همراه پلاس) با استراتژی
«قفل روی سقف» + تخصیص مساوی یک‌سوم + حد سود و حد ضرر لات‌محور.

## اجزا
- `warrobot/` : استراتژی، زمان‌بند، اسکن کاندیدا، سفارش‌گذاری، حد سود/ضرر، ایجنت‌ها
- `tese-robot/` : وب‌اپ گزارش‌دهی و داشبورد
- `history/` : تاریخچهٔ عملکرد (معاملات، سود/زیان، گزارش دوره‌ها)

## استراتژی فعلی
- ورود: نماد قفل‌شده روی سقف روزانه (High == Close و Close ≥ PrevClose×1.029)
- تخصیص: هر پوزیشن ≈ یک‌سوم دارایی
- خروج: حد سود ۲۵٪ (لات‌محور)، حد ضرر ۳٪، حداکثر نگهداری ۱۵ روز
- زمان سفارش: ۰۸:۴۵:۰۱ در پیش‌گشایش

## امنیت
اعتبارنامه‌ها، کوکی نشست، پروفایل مرورگر و داده‌های خام در مخزن نیستند.
