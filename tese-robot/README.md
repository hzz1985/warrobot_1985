## ۲. قواعد ایمنی که در کد اعمال شده‌اند

| قاعده | جای پیاده‌سازی | چه چیزی را جلوگیری می‌کند |
|---|---|---|
| حداکثر **یک** قصد سفارش برای هر (روز، سمت، نماد) | `orders.py:create` | خرید تکراری ۳ برابری وایرا |

| هیچ فروشی قبل از ۰۹:۰۰ یا بعد از ۱۲:۳۰ | `calendar_ir.is_open_for_sell` | فروش ساعت ۰۳:۳۰ بامداد |
| سقف ارزش هر پوزیشن و سقف کل Exposure | `risk.plan_buy` | تمرکز ۸۵٪ در یک نماد |
| حد ضرر روی قیمت واقعی و با تشخیص «صف فروش» | `risk.decide_exit` | تلاش بی‌پایان برای فروش در صف فروش |
| یک دفتر حسابداری Append-only با کلید یکتا | `ledger.py` | اختلاف ۲–۳ برابری با کارگزار |
| بازسازی پوزیشن از فیل‌های کارگزار، نه از اسنپ‌شات UI | `engine.sync` | شمارش دوباره (۵۱۶ در برابر ۲۵۸) |
| `days_held` بر پایهٔ تقویم معاملاتی و تاریخ فیل | `engine.scan_exits` + `calendar_ir` | صفر ماندن همیشگی روزهای نگه‌داری |

## ۴. مدل استراتژی — صف خرید با دوام (queue_v3)

هدف: خرید سهمی که **فردا صف خرید می‌خورد و صفش ≥۳ روز دوام می‌آورد**.
مدل `queue_v3` با ۵۱ فیچر (روزانه + درون‌روز + Burst) این احتمال را می‌دهد؛
جزئیات کامل در `docs/DURABLE_QUEUE.md`.

خلاصهٔ اعتبارسنجی walk-forward: AUC ۰٫۹۲۳ (full) و ۰٫۸۸۵ (daily)،
دقت top-3 برابر ۱۳٪ در برابر نرخ پایهٔ ۱٫۹٪ (lift ≈ ۷×).
آزمون اقتصادی: ۳۱ معامله، برد ۶۱٪، میانگین +۶٫۵٪ (مدل daily) و
۹ معامله، برد ۸۹٪، میانگین +۱۳٫۳٪ (مدل full).

> بخش زیر (rules_v2) فقط به‌عنوان fallback باقی مانده است.

سیگنال **رتبه‌محور** است، نه احتمال. هشت زیرامتیاز (هر کدام ۰..۱) با وزن‌های قابل تنظیم ترکیب می‌شوند:

| زیرامتیاز | منطق |
|---|---|
| `low_intraday_volume` | حجم کم نسبت به میانگین ۵ روز = آرامش قبل از صف |
| `volume_contraction` | انقباض حجم ۱۰ روزه |
| `no_recent_down` | بدون رشتهٔ نزولی اخیر |
| `near_ceiling` | نزدیک سقف دامنه ولی **هنوز قفل‌نشده** (روز قفل قابل خرید نیست) |
| `range_compression` | دامنهٔ روزانهٔ فشرده |
| `rsi_mid` | RSI در ناحیهٔ میانی (پرهیز از اشباع خرید) |
| `dist_from_52w_high` | فاصلهٔ ۵ تا ۳۵ درصد از سقف ۵۲ هفته |
| `low_reopen` | گپ بازگشایی کوچک مثبت |

خروج پیش‌فرض **`queue`**: تا وقتی نماد روی صف خرید قفل است نگه می‌دارد و در اولین روزی که صف می‌شکند می‌فروشد؛ حد ضرر ۳٪ و سقف نگه‌داری ۱۰ روز.
